POINTS TO REMEMBER:
**
*for a single try block there can be multiple catch blocks
*if it exits the try block and goes to catch it doesnt go to try again
** so what we do is add only related tasks in the try so that even if we gets out of the try function it doesnt effect other tasks in try block

lets understand about finally block 
finally{//lines of code}

this block gets executed everytime, wether the try is good(executed completely) or bad(error)

complete worflow::

public class EDemo {

    public static void main(String[] args) {

        //our starting lines of code
        System.out.println("From the start of the main...");
        //lets add code in try block which can produce any error
        try {
            //all related tasks i.e; dependent tasks
            //such that if terminated it doesnt affect our other tasks
        }
        //adding catch for the expected errors in try block
        //lets assume we have array out of index error
        catch (ArrayIndexOutOfBoundsException e) {
            
            //particular block of codes to counter the ArrayIndexOutOfBoundsException error or to show it
        }
        // adding other catch block
        //lets assume the other error we could face is of ArithmeticException
        catch (ArithmeticException ae){
            
            //particular block of codes to counter the ArithmeticException error or to show it
        }
        finally{
            
            //the block of codes which u want to execute always : not worried of the try function
        }

        //the end program
        System.out.println("From the end of the main...");
    }
}
